# Instruções para o Antigravity

Você deve ajudar a montar um chatbot comercial para a SOMO, sem usar n8n.

Use os arquivos desta pasta como base.

## Objetivo do projeto

Criar um chatbot híbrido para captar leads, responder dúvidas e encaminhar para atendimento humano.

## Stack inicial

- Typebot para fluxo visual
- Gemini API para IA
- Teste por link antes de WhatsApp
- Sem n8n

## Modelos escolhidos

1. Menu / botões
3. Chatbot com IA
5. Híbrido bot + humano

## Entregáveis esperados

- Fluxo organizado
- Prompt configurado
- Variáveis de captura
- Respostas comerciais
- Encaminhamento para especialista

## Regras

Não criar integração complexa no primeiro MVP.
Não depender de WhatsApp no início.
Não inventar preços.
Priorizar teste rápido e gratuito.
