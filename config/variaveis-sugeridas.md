# Variáveis sugeridas no Typebot

Use estas variáveis para organizar os dados coletados:

- nome
- empresa
- whatsapp
- servico_interesse
- principal_problema
- urgencia
- origem_conversa
- resumo_atendimento

## Exemplo de resumo para humano

Novo lead captado pelo chatbot SOMO:

Nome: {{nome}}
Empresa: {{empresa}}
WhatsApp: {{whatsapp}}
Serviço de interesse: {{servico_interesse}}
Principal problema: {{principal_problema}}
Urgência: {{urgencia}}
Origem: {{origem_conversa}}
